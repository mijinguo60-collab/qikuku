# Mumi 口播视频

## 推荐的第一版流水线

1. 用 `mumi-writer` 产出 30–90 秒口播稿，短句、停顿、重音和画面动作分行。
2. 用一个已获授权的人声或合成声生成 WAV；保存音频来源、说话人授权和生成参数。不要克隆第三方声音。
3. 先做“企鹅角色卡 + 轻微头部/翅膀关键帧 + 屏幕录制”，再尝试音频驱动口型。三只企鹅一起做复杂口型容易破坏 IP 一致性。
4. 用 FFmpeg 或本地剪辑工具合成画面、口播、字幕和音效；先输出无平台水印的母版，再分别导出抖音 9:16 版本。
5. 人工检查口型、字幕、工具界面、事实、AI 标识和音乐授权。生成项目不等于可发布视频。

## 开源项目选择原则

优先使用 [语音与视频项目评估表](references/audio-video-stack.md) 中的推荐级别；对模型权重、训练数据、第三方检测模型和输出商用权分开核验。仓库代码是 MIT 不代表模型权重也能商业使用。

## 口播画面模板

- 0–2 秒：企鹅惊讶/举牌，字幕直接说痛点；
- 2–10 秒：中企鹅指向录屏，展示输入材料；
- 10–45 秒：分两到三段展示操作，每段切一次镜头；
- 45–70 秒：展示结果和失败边界；
- 70–90 秒：底部企鹅托住收藏/评论提示，不做站外导流。
