# Mumi 写作质检

不要把“看起来顺”当成通过。先做硬扫描，再做真人阅读。只按本文件和 Mumi 定位判断，不引入其他作者的口癖。

## L1 硬规则

- 扫描并改写：首先、其次、最后、综上所述、值得注意的是、不难发现、让我们来看看、接下来我们、在当今时代、随着……发展、总的来说。
- 删除空泛词：赋能、抓住风口、降本增效、提升效率、实现闭环、全面升级、颠覆、革命性、无疑、非常、真正、只需、轻松、必然。
- 检查每个结论是否有工具名、操作、样例或实测证据。
- 检查是否出现禁止工具名、翻墙暗示、收益保证、虚构案例、未标注的 AI 生成内容。
- 检查代码、提示词和参数是否可复制，中文标点和数字是否一致。

## L2 去 AI 味

删掉“这不是 X，而是 Y”“问题不在 X，在 Y”“让我们一起”“你可能会发现”等预设式转折。把被动句改成明确的操作者，把“数据告诉我们”改成“我查看了数据后发现”。把抽象结论换成一个具体场景或失败动作。连续三句长度相似时改一处节奏，但不要靠碎片句伪造口语感。

## L3 内容质量

逐条回答：读者在第一个屏幕知道要做什么吗？准备材料写清了吗？步骤能复现吗？结果有证据还是只有形容词？原理是否足够解释选择？失败点是否给出排查动作？工具是否真的适合目标人群？

## L4 真人终审

通读并标记最像“模板”的段落。删掉过度整齐的三段论和口号，把其中一处换成真实的观察、犹豫、失败或限制。保留作者负责的判断，不用“可能、也许、通常”连续回避结论。

L3 内容质量：通过 / 返工（缺失证据）
L4 真人终审：通过 / 返工（最模板化段落）

最终状态：可发布 / 需要实测 / 不可发布
