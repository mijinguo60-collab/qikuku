# Mumi 企鹅视觉与生图

先读 [企鹅 IP 规范](references/penguin-ip.md) 和 [风格原子](references/style-atoms.md)。必要时使用仓库中的 `assets/penguin/` 两张参考图。生图提示词按“主体—场景—风格—构图—技术约束”编译，输出一段自然语言 prompt，不把要求拆成互相矛盾的词袋。

## 选择流程

1. 从选题提取一个视觉隐喻：工具、步骤、失败点或结果，只选一个主隐喻。
2. 在风格原子中选一套，系列内固定使用；不要同时混合摄影、像素、纸雕等语言。
3. 选择角色状态：基础叠罗汉、黄色外套版、单只近景或三只完整出镜。没有请求时默认三只完整叠罗汉。
4. 从 [表情动作矩阵](references/penguin-ip.md) 选 1 个主表情 + 1 个主动作，不要堆成动作清单。
5. 设定画幅：小红书图文 3:4，抖音封面/视频 9:16，公众号头图按排版需要保留横向安全区。封面文字留 25% 安全留白，中文长标题后期叠字。
6. 输出封面 prompt、内页 prompt、负面约束和后期叠字建议。图片真正生成后再记录模型、参考图、尺寸和人工复核结论。

## 一致性硬约束

- 三只企鹅始终是黑色圆润身体、白色脸/腹部区域、橙色嘴和脚；保留手绘不规则轮廓。
- 叠罗汉关系必须可读：上小、中大、下最大，脚和身体有真实接触；不要凭空增加第四只。
- 黄色大外套只在“外套版”使用，外套是宽松明黄，不能变成西装、制服或其他品牌服装。
- 不给企鹅添加真实人脸、复杂写实羽毛、品牌 logo、第三方角色或无法解释的道具。
- 同一系列固定色彩与线条，改变的是动作、道具和信息隐喻，不是角色物种。

## 交付格式

```markdown
系列：<系列名>
风格原子：<id>
画幅：<比例>
主体 prompt：<一段自然语言>
构图 prompt：<一段自然语言>
禁止漂移：<角色锚点>
后期叠字：标题 / 副标题 / 安全区
```
