# Mumi 原创风格原子

这些是可组合的视觉语法，不复制 Punk-Skill 的源文件、原提示词或示例图。每个系列只选一个主风格，最多配一个材质变化。

| ID | 风格语法 | 适合题材 |
| --- | --- | --- |
| `clean-editorial` | 近白底、黑色线稿、少量明黄与橙色点缀、大留白、单一视觉隐喻 | 工具教程、方法论 |
| `paper-cut-workflow` | 分层纸张、柔和投影、纸片流程节点、平面化背景 | 工作流、步骤拆解 |
| `ink-notebook` | 米白纸张、手写线条、荧光黄标记、像实测笔记 | 体验、避坑、复盘 |
| `retro-tech-poster` | 复古印刷颗粒、蓝黑底、橙黄高亮、强几何构图 | 工具对比、效率 |
| `soft-block-world` | 圆角积木、简化空间、清晰前中后景、可读的单一目标 | 搭建、自动化 |
| `flat-sticker` | 纯色块、粗线、贴纸边缘、透明或浅色底 | 小红书内页、公众号装饰 |
| `research-board` | 档案板、索引标签、截图占位框、克制色彩 | 实测报告、对比 |
| `warm-comic` | 暖色纸张、两到三格叙事、动作线少而准 | 失败故事、口播封面 |
| `minimal-isometric` | 小型等距场景、干净投影、企鹅作为场景角色 | 系统搭建、流程全景 |
| `mono-orange-alert` | 黑白主画面、橙色只标风险点、强对比安全区 | 误区、风险、合规 |
| `bright-desk` | 俯拍桌面、纸张与工具道具、企鹅探头或站立 | 提示词、模板、资料包 |
| `cinematic-flat` | 平面插画角色配轻微光影和景深，动作清楚 | 视频封面、口播 |

## 选风格原则

教程优先 `clean-editorial` 或 `paper-cut-workflow`；实测复盘优先 `ink-notebook` 或 `research-board`；避坑用 `mono-orange-alert`；口播视频用 `cinematic-flat` 或 `warm-comic`。如果内容的主价值是可复制文本，使用 `bright-desk` 并把文字安全区留给后期排版。
