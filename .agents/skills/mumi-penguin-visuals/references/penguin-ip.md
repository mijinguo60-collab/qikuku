# Mumi 三企鹅 IP 规范

## 角色锚点

参考资产：`assets/penguin/penguin-stack-base.jpg`（基础版）和 `assets/penguin/penguin-stack-yellow-coat.jpg`（外套版）。这两张图是用户提供的原创 IP 参考，不把它们改造成新物种。

三只企鹅从上到下保持清晰层级：顶部最小，身体轻巧，负责反应和举牌；中部较大，负责讲解、指向和操作；底部最大，负责承托、展示结果和稳定画面。它们共享黑色身体、白色脸/胸、橙色嘴和脚，白色区域边缘保留不规则手绘感，眼睛简单、表情靠眼睛方向和嘴形表达。

基础版不穿衣服。外套版只有一件包住三只企鹅的宽松明黄色大外套，袖子和纽扣是简化手绘形，不新增帽子、眼镜、鞋或 logo。若题材需要工具，工具放在手上或身旁，不能遮住三只脸和叠罗汉结构。

## 动作矩阵

- 讲解：中企鹅伸翅膀指向左侧步骤卡，顶部企鹅看向卡片，底部企鹅稳住画面。
- 录屏：中企鹅拿平板，顶部企鹅探头看屏幕，底部企鹅托住平板；屏幕只留空白界面，后期叠真实截图。
- 试错：顶部企鹅拿问号牌，中企鹅翻倒一张流程卡，底部企鹅做支撑；动作要有接触关系。
- 成功：三只保持叠罗汉，顶部举小旗，中部举结果卡，底部站稳；不做夸张飞行。
- 搭建：三只共同搬运一块积木或流程模块，模块不遮脸。
- 口播：嘴部动作幅度小，头部只做轻微点头、侧看、停顿；不做真人嘴唇式夸张变形。
- 分隔装饰：单只或三只缩小成贴纸，靠边站立或探头，不压正文。

## 一致性检查

生成前后逐项核对：是否正好三只；上下大小关系是否仍在；黑白橙三色是否稳定；嘴和脚是否橙色；是否误加衣物/角色；动作是否能读出；是否留出文字安全区；是否需要后期叠字而不是让模型写长中文。
