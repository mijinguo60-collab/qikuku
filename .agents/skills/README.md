# Mumi聊Ai 内容技能包

这是给 Mumi 使用的个人自媒体内容生产技能包，覆盖：

- `mumi-content-pipeline`：四步总管线；
- `mumi-topic-research`：选题调研；
- `mumi-writer`：四平台写作；
- `mumi-copy-review`：去 AI 味与发布前质检；
- `mumi-penguin-visuals`：三企鹅 IP、多表情、多动作和生图提示词；
- `mumi-gzh-design`：微信公众号内联 HTML 排版；
- `mumi-voice-video`：企鹅口播的声音、动画和后期路径。

安装或同步后，优先调用 `$mumi-content-pipeline`，其他 skills 作为子流程独立调用。

账号定位：Mumi｜不讲虚的，只讲能直接抄走的 AI 干货。所有内容先实测，再发布；图像和口播统一使用三只叠罗汉企鹅 IP。
